# 第一步：确定轻量浏览器 MVP 范围和验收标准

## 目标

把当前 Electron 空壳做成一款可日常试用的基础浏览器：能打开网页、管理标签，并提供最基本的书签、历史记录和下载能力。本阶段只确定范围与验收标准，不实现浏览器功能。

## MVP 范围

### 包含

- **窗口与标签**：单个主窗口；新建、切换、关闭标签；关闭最后一个标签时保留窗口并显示新标签页；网页标题显示在标签上。
- **地址栏与导航**：输入完整网址或域名可导航；输入普通文本使用默认搜索引擎搜索（首版暂定 DuckDuckGo）；支持前进、后退、刷新和加载状态。
- **弹出窗口**：网页请求打开新窗口时，在新标签中打开，不额外创建不受管理的窗口。
- **书签**：添加当前页面、查看书签、删除书签；重启应用后仍保留。
- **历史记录**：记录成功访问的网页标题、网址和时间；提供查看与清空；重启应用后仍保留，最多保留最近 1,000 条。
- **下载**：下载到系统默认下载目录；展示当前运行期间的下载进度、完成或失败状态；可打开已完成文件所在位置。下载记录不要求跨重启保留。
- **常用快捷键**：新建/关闭标签、聚焦地址栏、刷新、前进/后退；按 macOS 的 Command 键习惯实现。
- **实现边界**：沿用当前原生 HTML/CSS/JavaScript，不引入前端框架；本地浏览器界面使用 `BrowserWindow`，网页标签使用 `WebContentsView`。
- **安全基线**：浏览器界面保持 `contextIsolation`、sandbox 开启和 `nodeIntegration` 关闭；网页不能直接访问 Node.js；仅支持 `http:` / `https:` 网页导航，权限默认拒绝。
- **首轮验证平台**：当前 macOS Intel 开发机。跨平台打包和签名放到 MVP 之后评估。

### 暂不包含

- Chrome 扩展、账号同步、多用户/多配置、密码管理、自动填表。
- 广告或跟踪拦截、阅读模式、垂直标签组、开发者工具定制。
- 无痕模式、云端同步、导入导出、复杂搜索建议或可视化设置中心。
- `file:`、`javascript:` 等非 HTTP(S) 页面；修改 Chromium/Blink/网络栈。
- 跨平台发行包、自动更新、代码签名与正式发布流程。

## 验收标准

1. `npm start` 可启动单窗口并显示新标签页；应用启动时无未处理异常。
2. 地址栏能打开 `https://example.com` 和 `example.com`；普通文本会进入默认搜索；不支持的协议不会在应用中执行或导航。
3. 连续打开至少 3 个网页标签后，切换标签显示对应网页；新建、关闭标签均有效；关闭最后一个标签后窗口仍可用并显示新标签页。
4. 前进、后退、刷新与网页加载状态对应当前标签；切换标签不会把操作误发给其他页面。
5. 网页标题更新到对应标签；网页弹出新窗口的请求会变成新标签，不会创建额外浏览器窗口。
6. 可添加、查看和删除书签；重启应用后变更仍在。
7. 访问网页后历史记录出现对应标题、网址和时间；可清空；重启后保留；记录数不超过 1,000 条。
8. 下载文件时能看到进度和最终状态；完成后能打开文件所在位置；下载失败时显示失败状态。
9. 上述常用快捷键在 macOS 上生效；焦点在地址栏和网页内容时均符合预期。
10. 网页无法直接调用 Node.js 或任意 IPC；权限请求默认拒绝；非 HTTP(S) 导航被拦截。

## 验收说明

浏览器网页本身可能改变、拒绝嵌入或要求登录，因此验收以基础网页加载、标签行为和本地控制功能为准，不把特定网站的布局或登录成功作为通过条件。内存和 CPU 暂不设硬阈值，先避免空闲时持续轮询，并记录实际启动与浏览时的资源占用。

## 后续实施顺序

范围确认后，先搭窗口布局和 `WebContentsView` 标签生命周期，再实现地址栏/导航；随后补书签、历史和下载，最后集中做安全及回归验收。
