# 轻量浏览器 MVP

目标是在现有 Electron 骨架上实现基础浏览器能力，不 fork Min，也不从源码构建 Chromium。

## MVP 范围与验收

第一阶段范围、暂不包含的功能及逐项验收标准见 [01_小步可运行、先浏览再补配套功能.md](./01_%E5%B0%8F%E6%AD%A5%E5%8F%AF%E8%BF%90%E8%A1%8C%E3%80%81%E5%85%88%E6%B5%8F%E8%A7%88%E5%86%8D%E8%A1%A5%E9%85%8D%E5%A5%97%E5%8A%9F%E8%83%BD.md)。

## 实施阶段

1. ✅ 确定 MVP 边界和验收标准。
2. ✅ 使用 `BrowserWindow` 承载本地浏览器界面，使用 `WebContentsView` 展示网页。
3. ✅ 实现标签创建、切换、关闭、最后一个标签回退及网页弹窗转新标签。
4. ✅ 实现地址/搜索栏、前进/后退/刷新和加载状态。
5. ✅ 增加基础书签、历史记录、下载列表和常用快捷键。
6. ✅ 完成安全检查和回归验收；跨平台打包发布仍留待 MVP 之后评估。

本机验证：`npm run check`、`npm test`（7 项）和 `npm audit` 均通过；以本地测试网页验证了地址栏快捷键、导航、书签/历史、下载完成状态、弹窗转标签及网页隔离。

## 实现约束

- 首版沿用原生 HTML/CSS/JavaScript，暂不添加前端框架。
- 网页不直接获得 Node.js 能力；主进程只通过受限、校验过的 IPC 暴露浏览器操作。
- 保持 Electron 安全默认值，使用 `WebContentsView`，不新建基于 `<webview>` 或已弃用 `BrowserView` 的实现。
